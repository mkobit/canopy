# Canopy graph kernel

## Overview

This directory implements the `@canopy/graph` core domain kernel: branded identifiers, temporal wrappers, immutable `Node`/`Edge`/`Graph` structures, Zod schemas, `Result` error handling, `EventLogStore`/`ReadModelPort` ports, system bootstrap definitions, LWW and order-independent incremental projection, read-model indexes, time-travel queries, `GraphSession`/`DraftSession`/`EventBus` orchestration, schema/WASM plugin validation, and workflow action execution.

## Interface

## Invariants

- Domain IDs (`NodeId`, `EdgeId`, `ShapeId`, `PropertyTypeId`, `BatchId`, `GraphId`, `EventId`, `DeviceId`, `Namespace`, `Revision`, `CommitSeq`, `PrincipalId`, `ActorId`) and temporal primitives (`Instant`, `PlainDate`, `HlcTimestamp`) are branded with unique symbols; `Node.shape`, `Edge.shape`, `NodeCreated.shapeId`, and `EdgeCreated.shapeId` are optional `ShapeId` (`undefined` for open entities); core entities and collections use `Readonly`/`ReadonlyMap`/`readonly`.
- `[event-upcast.ts:decodeStoredEvent]` Pure, stateless read-side upcaster normalizes legacy `nodeType`/`edgeType`, strips retired `canopy:open` sentinel, and (when `remapRetiredMetaShapes` is enabled) remaps retired meta-shapes (`node:type:node-type`, `node:type:edge-type`) to `node:type:shape` and skips retired meta-node lifecycle events as `ok(null)` before validating with `GraphEventSchema`, rejecting dual-field conflicts without throwing.
- `[bootstrap.ts:bootstrap]` Is idempotent across node and edge steps, attributes authorship to `SYSTEM_DEVICE_ID` (`00000000-0000-0000-0000-000000000000`), and short-circuits on the first `Err`.
- `[projection.ts:lwwWins]` Orders writes by effective `HlcTimestamp` (synthesizing from `(timestamp, deviceId)` for legacy events) with `deviceId` as tiebreaker; `[incremental-projection.ts:mergeEvents]` converges to `projectGraph(sort(E), initialGraph)` regardless of arrival order, parking unmet dependencies atomically by `batchId`, permanently tombstoning deleted entities, and tracking `headCommitSeq` and per-entity `entitySeqs` (including cascade-deleted edges).
- `[indexes.ts:incrementalUpdateIndexes]` Maintains read-model indexes in O(delta) for normal events and triggers a full `buildGraphIndexes` rebuild on config-mutating events (`VIEW_OVERRIDE`, `DEFAULT_VIEW`, `SETTINGS_SCHEMA`, `USER_SETTING`); direct `ops/*` graph mutations reset `_indexes` to `undefined` on returned graph snapshots to prevent stale reads.
- `[revision.ts:accumulateRevision]` Performs commutative modular addition over 122-bit hashes so revision advances identically regardless of event order.
- `[batch-validation.ts:validateBatch]` Rejects `NodeDeleted` on system nodes (`isSystemNodeId`), dry-run projects, and validates touched nodes/edges before appending to `EventLogStore`; `[graph-session.ts:createGraphSession]` is the single writer per `graphId`, serializes `load`/`commit`, stamps `hlcTimestamp`, `commitSeq`, `principalId`, `actorId`, and `deviceId`, enforces `unconditional`/`entity-cas`/`graph-cas` preconditions, and enforces `minCommitSeq`, `atCommitSeq`, `atTimestamp`, and `linearizable` read gates in `readGraph`; `[draft-session.ts:createDraftSession]` shares `validateBatch`, enforces optimistic concurrency on `parentSession.graph().revision`, and maps `'concurrency-conflict'` to `'concurrent-modification'`.
- `[plugin-validation.ts:RECOGNIZED_WASM_CAPABILITIES]` Must stay identical to `KNOWN_WASM_CAPABILITIES` in `@canopy/plugin-host`; `[validation.ts:validateNode]` / `[validation.ts:validateEdge]` enforce 8192-char regex bounds, cardinality, and `SHAPE_INACTIVE` checks (`error` on `'create'`, `warning` on `'update'`).

## Side Effects

- `[factories.ts]`, `[constructors.ts]`, `[bootstrap-definitions.ts]`, `[bootstrap.ts]`, `[create-graph.ts]`, `[workflow-engine.ts]` Read system randomness (`uuidv7`) and wall-clock time (`Temporal.Now.instant()`).
- `[indexes.ts:getGraphIndexes]` Inserts computed indexes into the module-level `graphCache` `WeakMap`, mutates `graph._indexes`, and deep-freezes parsed `userSettings` values.
- `[graph-session.ts:createGraphSession]`, `[draft-session.ts:createDraftSession]`, `[event-bus.ts:createEventBus]`, `[workflow-engine.ts:createWorkflowTriggerRegistry]` Mutate internal closure state cells, call `EventLogStore` async methods (`getEvents`, `appendEvents`), and synchronously invoke subscriber callbacks.
- `[plugin-validation.ts:brotliDecompressSync]` Attempts module-load-time `require('node:zlib')`; `[result.ts:unwrap]` throws `result.error` when `!result.ok`.
