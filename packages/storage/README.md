# `@canopy/storage`

## Overview

The `@canopy/storage` package re-exports `@canopy/graph`'s `EventLogStore` port types and provides the in-memory `EventLogStore` implementation (`createInMemoryEventStore`).

## Subdirectories & Boundaries

- Source: [src](./src/README.md) — `EventLogStore` type re-exports and `createInMemoryEventStore`.
