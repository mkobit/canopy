# Graph access layer

## Overview

This directory implements the generated `canopy.v0` TypeSpec contracts, server route dispatcher/handlers, shared TypeScript client SDK, typed request/response contracts, error mapping, query/traversal handlers, session-backed mutation handlers, and live/replay event stream handlers for accessing Canopy graphs. It enforces consistency preconditions (`Entity CAS`, `Graph CAS`, `minCommitSeq`), query depth/cost/limit bounds, and `Result`-based error handling across all operations.

## Interface

- `[index.ts:*]` Re-exports all symbols from `canopy-v0-client`, `canopy-v0-contract`, `canopy-v0-server`, `event-stream-handlers`, `graph-access-context`, `graph-access-payloads`, `mutation-handlers`, `query-handlers`, and `result-errors`.
- `[canopy-v0-contract.ts:*]` Autogenerated from `../typespec/main.tsp`: `CANOPY_V0_SERVICE_TITLE`, `CANOPY_V0_CONTRACT_VERSION`, `CANOPY_V0_ROUTES`, scalar/enum/model DTO types across `Graphs`, `Transactions`, `Queries`, `Views`, `Bundles`, and `Streams`, and `CanopyV0ServiceHandlers`.
- `[canopy-v0-server.ts:CanopyV0RouteRequest]`, `[canopy-v0-server.ts:CanopyV0RouteResponse]`, `[canopy-v0-server.ts:CanopyV0ServerRouter]`, `[canopy-v0-server.ts:createCanopyV0InProcessHandlers]`, `[canopy-v0-server.ts:createCanopyV0ServerRouter]` In-process multi-graph `canopy.v0` handlers and HTTP-compatible route dispatcher.
- `[canopy-v0-client.ts:CanopyV0Transport]`, `[canopy-v0-client.ts:CanopyV0FetchFunction]`, `[canopy-v0-client.ts:CanopyV0FetchTransportOptions]`, `[canopy-v0-client.ts:CanopyV0ClientGraphs]`, `[canopy-v0-client.ts:CanopyV0Client]`, `[canopy-v0-client.ts:createInProcessCanopyV0Transport]`, `[canopy-v0-client.ts:createFetchCanopyV0Transport]`, `[canopy-v0-client.ts:createCanopyV0Client]` Shared TypeScript client SDK over in-process router or HTTP `fetch` transport.
- `[graph-access-context.ts:GraphAccessAuthContext]`, `[graph-access-context.ts:GraphAccessLimits]`, `[graph-access-context.ts:defaultGraphAccessLimits]`, `[graph-access-context.ts:GraphAccessContext]`, `[graph-access-context.ts:createGraphAccessContext]` Auth context, limits, and context factory.

## Invariants

- `[canopy-v0-contract.ts]` Must match deterministic output from `bun tools/typespec-codegen.ts` (`packages/graph-access/typespec/main.tsp`).
- `[canopy-v0-server.ts:createCanopyV0InProcessHandlers]` Serializes per-`graphId` mutators (`createGraph`, `deleteGraph`, `commitTransaction`, `createDraft`, `stageDraftOperations`, `commitDraft`, `discardDraft`, `installBundle`, `registerShapeMigration`) via `withGraphWriteLock`, enforces `entity-cas` / `graph-cas` write preconditions (`CONCURRENCY_CONFLICT`), `minCommitSeq` read-your-writes, `RenderSelector` cycle/depth guards on `resolveView`, 5-level `resolveSetting` cascade, `activationKeyRequired` bundle gating (`FORBIDDEN`), optional `shapeId` on open edges, `canonicalizeUri` validation + indexed `SYSTEM_IDS.PROXY` lookup on `queryNodes.canonicalUri`, `warnings` + `GraphAccessError.details` on `commitTransaction`/`commitDraft`, and `valueKind`/`constraints`/`inline` schema projection (mapping legacy `'list'` to `'text'` + `'many'`).
- `[graph-access-context.ts:defaultGraphAccessLimits]` Defaults to `maxQueryDepth=10`, `maxQueryCost=1000`, `maxStreamBuffer=1000`.
- `[event-stream-handlers.ts:createEventStreamSubscriber]` Defaults `bufferCapacity` to `100`, emits `'overflow_disconnect'` and closes on overflow, and emits `'end'` once on `close()`.
- `[event-stream-handlers.ts:executeReplayEventStream]` Requires `eventLogStore` (`'VALIDATION_ERROR'`), defaults `maxReplayCount` to `1000`, and emits `'gap'` when unacknowledged events exceed `maxReplay`.
- `[mutation-handlers.ts:*]` Require `context.session` (`'VALIDATION_ERROR'`), reject duplicate IDs (`'CONCURRENCY_CONFLICT'`), accept optional `shapeId` (falling back to `type`, omitting `shape` when undefined for open entities), and cascade `EdgeDeleted` events on `executeDeleteNode`.
- `[query-handlers.ts:*]` Cap `executeEdgeQuery` at `1000` edges, and clamp `executeGraphTraversal` to `maxQueryDepth` / `maxQueryCost` (`'RESOURCE_EXHAUSTED'` on cost overflow).

## Side Effects

- `[canopy-v0-server.ts:createCanopyV0InProcessHandlers]` Maintains encapsulated in-memory graph registry, draft map, and commit log state, and commits events via `GraphSession.commit`.
- `[canopy-v0-client.ts:createFetchCanopyV0Transport]` Issues HTTP `fetch` requests against `baseUrl`.
- `[graph-access-payloads.ts:createGraphAccessRequest]` Reads `Temporal.Now.instant().epochMilliseconds` when `timestamp` is omitted.
- `[event-stream-handlers.ts:createEventStreamSubscriber]` Subscribes to `context.session.subscribe`, mutates internal closure state, and invokes listener callbacks; `executeReplayEventStream` reads `context.eventLogStore.getEvents`.
- `[mutation-handlers.ts:*]` Call `session.commit(...)` and generate IDs/timestamps via `createNodeId`, `createEdgeId`, `createEventId`, and `createInstant`.
