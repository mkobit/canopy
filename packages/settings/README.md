# `@canopy/settings`

## Overview

The `@canopy/settings` package implements the 5-level scoped settings cascade (`node`, `type`, `namespace`, `global`, and schema default), `USER_SETTING` node creation, and 3-step `ViewDefinition` resolution on top of `@canopy/graph`.

## Subdirectories & Boundaries

- Source: [src](./src/README.md) — Settings cascade resolution (`resolveSetting`, `findSettingsSchema`), `addUserSetting`, and `resolveViewDefinition`.
