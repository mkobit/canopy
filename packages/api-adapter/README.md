# `@canopy/api-adapter`

## Overview

The `@canopy/api-adapter` package adapts `@canopy/graph-access` operations into Connect-RPC, GraphQL, and JSON-RPC 2.0 over Unix domain socket (IPC) transport surfaces.

## Subdirectories & Boundaries

- Source: [src](./src/README.md) — Package barrel exports, `GraphAccessError` mappers, and `./connect/README.md`, `./graphql/README.md`, `./ipc/README.md` adapters.
