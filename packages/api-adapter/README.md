# `@canopy/api-adapter`

## Overview

The `@canopy/api-adapter` package adapts `@canopy/graph-access` operations into JSON-RPC 2.0 over Unix domain socket (IPC) transport surfaces (Connect and GraphQL adapters purged under `canopy-anir.2.1`).
