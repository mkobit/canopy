# `@canopy/plugin-host`

## Overview

The `@canopy/plugin-host` package provides the WebAssembly Interface Types (WIT) host boundary, capability validation, fuel/memory/reentrancy/timeout-guarded guest execution, and WIT error mapping over `@canopy/graph-access`.

## Subdirectories & Boundaries

- Source: [src](./src/README.md) — `toWitError` mapper and `./wasm/README.md` (WIT spec, capability/tier resolution, host bindings, and sandboxed/terminable executors).
