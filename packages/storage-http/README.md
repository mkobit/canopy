# `@canopy/storage-http`

## Overview

The `@canopy/storage-http` package implements an HTTP `fetch` client adapter (`HTTPEventLog`) for `@canopy/graph`'s `EventLogStore` port.

## Subdirectories & Boundaries

- Source: [src](./src/README.md) — `createHTTPEventLog` client adapter and `GraphEvent` HTTP payload serialization.
