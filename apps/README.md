# Applications

## Overview

This directory groups the runnable Canopy CLI and web applications.

## Subdirectories & Boundaries

- CLI: [cli](./cli/README.md) — `@canopy/cli` Effect CLI root entrypoint (`canopy`, pending `canopy.v0` TypeSpec client SDK commands).
- Web: [web](./web/README.md) — `@canopy/web` React SPA for graph exploration, editing, schema authoring, stored views, and WASM plugin rendering.
