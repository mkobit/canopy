# `@canopy/cli`

## Overview

The `@canopy/cli` application provides the `canopy` Effect CLI client that connects to the Canopy daemon over a Unix domain socket to inspect and mutate graph state, run queries, and stream events.

## Subdirectories & Boundaries

- Source: [src](./src/README.md) — Effect CLI entrypoint (`index.ts`), `--socket-path`/`--json` flags, custom CLI output/diagnostic formatting, and `./commands/README.md`.
