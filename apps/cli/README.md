# `@canopy/cli`

## Overview

The `@canopy/cli` application provides the `canopy` Effect CLI root entrypoint (`rootCommand`), pending `canopy.v0` TypeSpec client SDK commands.

## Subdirectories & Boundaries

- Source: [src](./src/README.md) — Effect CLI entrypoint (`index.ts`) and custom CLI output/diagnostic formatting (`cli-output.ts`).
